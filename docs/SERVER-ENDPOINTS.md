# Endpoints שצריך להוסיף לשרת

הלקוח כבר קורא לכתובות האלה (`src/api/`). עד שהן יתווספו לשרת, הדפים הרלוונטיים יציגו הודעת שגיאה.
כל הכתובות דורשות `Authorization: Bearer TOKEN`, ושגיאות במבנה הקיים `{error:{code,message,details?}}`.

| Method | URL                           | הרשאה  | גוף / תשובה                                                                                  |
| ------ | ----------------------------- | ------ | -------------------------------------------------------------------------------------------- |
| GET    | `/api/rooms/{id}/leaderboard` | מחובר  | `{items:[{userName, seconds, completedAt}]}` – 10 הזמנים המהירים ביותר, מהקטן לגדול          |
| GET    | `/api/me/games`               | מחובר  | `{items:[{roomId, roomTitle, seconds, completedAt}]}` – משחקים שהסתיימו, מהחדש לישן          |
| GET    | `/api/admin/users`            | מנהל   | `{items:[{id,name,email,role}]}`                                                             |
| DELETE | `/api/admin/users/{id}`       | מנהל   | 204. 409 אם המשתמש הוא מנהל; מוחק גם את ההתקדמות שלו                                         |
| PATCH  | `/api/auth/me`                | מחובר  | גוף `{name}` ← `User` מעודכן                                                                 |
| POST   | `/api/auth/change-password`   | מחובר  | גוף `{currentPassword,newPassword}` ← 204. 401 `INVALID_CREDENTIALS` אם הסיסמה הנוכחית שגויה |
| POST   | `/api/auth/forgot-password`   | ציבורי | גוף `{email}` ← 202 תמיד (גם אם האימייל לא קיים)                                             |

## הערות

- **זמן במקום ניקוד.** `seconds` מחושב בשרת מ־`startedAt` עד `completedAt` של המשחק, כך שאי אפשר לזייף תוצאה
  מהלקוח. הלקוח לא שולח ניקוד. רמזים וטעויות מוצגים לשחקן במהלך המשחק בלבד, כי השרת לא שומר אותם.
- **לוח תוצאות:** ממיינים לפי `completedAt - startedAt`, ולוקחים לכל משתמש את הזמן הטוב ביותר שלו.
- **איפוס משחק:** `restart` מוחק את ההתקדמות, אז כדאי לשמור את המשחקים שהסתיימו בטבלה נפרדת (או לא למחוק
  משחק שהושלם) כדי שההיסטוריה ולוח התוצאות לא ייעלמו.
- **שכחתי סיסמה:** צריך שירות מייל וטוקן חד־פעמי. עמוד "איפוס סיסמה" (הקישור מהמייל) עדיין לא קיים בלקוח.
