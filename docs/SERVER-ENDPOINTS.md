# Endpoints בשרת שהלקוח משתמש בהם

הוספו לשרת (ענף `claude/server-endpoints` ב־`escape-room-server`, כולל migration, OpenAPI ובדיקות):

| Method | URL                           | הרשאה | הערות                                                            |
| ------ | ----------------------------- | ----- | ---------------------------------------------------------------- |
| GET    | `/api/rooms/{id}/leaderboard` | מחובר | 10 הזמנים המהירים ביותר, שיא אישי אחד לכל שחקן                   |
| GET    | `/api/me/games`               | מחובר | משחקים שהסתיימו, מהחדש לישן                                      |
| GET    | `/api/admin/users`            | מנהל  | רשימת משתמשים                                                    |
| DELETE | `/api/admin/users/{id}`       | מנהל  | 204; 409 `CANNOT_DELETE_ADMIN` על מנהל                           |
| PATCH  | `/api/auth/me`                | מחובר | `{name}`                                                         |
| POST   | `/api/auth/change-password`   | מחובר | 204; 403 `WRONG_PASSWORD` (לא 401, כדי שהלקוח לא ינתק את המשתמש) |

הזמן נמדד בשרת מתחילת המשחק ועד פתרון החידה הסופית. תוצאות נשמרות בטבלה נפרדת (`CompletedGame`),
ולכן `restart` ועריכת חדר לא מוחקים אותן.

## עדיין חסר

`POST /api/auth/forgot-password` – דורש שירות שליחת מייל (למשל Resend), טבלת טוקנים חד־פעמיים ועמוד
"איפוס סיסמה" בלקוח. עד אז הלקוח מציג "שחזור סיסמה אינו זמין כרגע".
